# Méditons Ensemble

Version actuelle : v3.3 (03/11/2026), en français et en anglais, aux couleurs or, bleu nuit, noir et blanc, avec le logo « Le Sceau » (M royal).

Application pour méditer la Bible chaque jour, avec un coach : méthode guidée en deux parties, Bible Louis Segond 1910 intégrée, enseignements écrits et vidéo, défis de lecture, quiz et bilan.

**Ouvrir l'application : https://mroyal-apps.github.io/meditons-ensemble/**

- Installable sur téléphone (« Ajouter à l'écran d'accueil ») et utilisable hors connexion.
- Les données restent sur l'appareil ; avec un compte (facultatif, e-mail + mot de passe), elles sont synchronisées entre l'ordinateur et le téléphone. Le compte peut être supprimé à tout moment depuis l'application.
- Langue : français ou anglais, avec un bouton FR · EN toujours visible.
- Textes bibliques : Louis Segond 1910, Darby 1885, Martin 1744, King James Version et World English Bible (domaine public), via le jeu de données ouvert midvash/bible-data.
